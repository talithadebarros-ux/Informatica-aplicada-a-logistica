# Atividade 04 — Análise de Dados de Fecundidade

## 📌 Descrição

Nesta atividade, tivemos acesso a diferentes dados governamentais abertos e ficamos livres para escolher um conjunto de dados de nossa preferência para trabalhar.

O conjunto escolhido apresenta informações sobre a fecundidade por idade no estado de São Paulo, abrangendo o período de 2000 a 2024.

## 🎯 Objetivo

O objetivo da atividade foi trabalhar com dados públicos, desenvolvendo habilidades de organização, análise e interpretação de informações a partir de uma base de dados governamental.

## 📊 Dados analisados

A base de dados utilizada contém informações relacionadas à fecundidade no estado de São Paulo, incluindo:

* Ano;
* Região;
* Número de nascidos;
* Fecundidade por faixa etária;
* Fecundidade total;
* Idade das mães.

Os dados abrangem o período de 2000 a 2024, permitindo a análise das informações ao longo dos anos.

## 🛠️ Desenvolvimento

A partir da base de dados escolhida, foram organizadas e analisadas as informações referentes à fecundidade por idade, utilizando os dados públicos disponíveis para o estado de São Paulo e elaborado 5 perguntas.

📂 Arquivo

* Arquivo da atividade — análise do conjunto de dados de fecundidade por idade no estado de São Paulo.
