# Atividade 02 — Análise de Dados de Transportes Multimodais

## 📌 Descrição

Nesta atividade, trabalhamos com dados disponibilizados pela ANTT (Agência Nacional de Transportes Terrestres) relacionados aos transportes multimodais.

A partir desses dados, utilizamos ferramentas do Microsoft Excel para organizar, analisar e interpretar as informações de forma mais clara e eficiente.

## 🎯 Objetivo

O objetivo da atividade foi desenvolver conhecimentos relacionados à análise e organização de dados, utilizando recursos disponíveis no Excel para facilitar a interpretação das informações.

## 🛠️ Desenvolvimento

Durante a atividade, os dados foram trabalhados e organizados utilizando ferramentas do Excel, permitindo uma análise mais estruturada das informações sobre os transportes multimodais.
