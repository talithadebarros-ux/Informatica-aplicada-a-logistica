# Atividade 03 — Operadores de Transporte Multimodal

## 📌 Descrição

Nesta atividade, trabalhamos com uma base de dados sobre Operadores de Transporte Multimodal (OTM).

A partir das informações disponíveis na base de dados, utilizamos ferramentas do Microsoft Excel para organizar, analisar e representar os dados de forma mais clara e visual.

## 🎯 Objetivo

O objetivo da atividade foi desenvolver habilidades de organização e análise de dados, utilizando recursos do Excel para transformar as informações em tabelas e gráficos que facilitassem sua interpretação.

## 🛠️ Desenvolvimento

Durante a atividade, os dados foram organizados e analisados por meio de tabelas e gráficos no Excel, permitindo representar as informações de maneira visual e facilitar a compreensão dos dados relacionados aos operadores de transporte multimodal.
