# Informatica aplicada á logística 
Este repositório reúne as atividades desenvolvidas até o momento na disciplina de Informática Aplicada à Logística. Ao longo das atividades, foram trabalhados diferentes conceitos e ferramentas relacionados à análise, organização e visualização de dados, aplicados a situações do contexto logístico.

A seguir, estão organizadas as atividades realizadas, apresentando o desenvolvimento dos projetos e os conhecimentos adquiridos durante a disciplina.
