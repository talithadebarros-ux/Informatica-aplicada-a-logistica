# 📊 Análise de Dados — Expectativa de Vida

## 📝 Sobre a atividade

Foi utilizada uma planilha de dados abertos sobre expectativa de vida, contendo diversas informações organizadas por entidades e códigos. A partir desses dados, foi desenvolvido um dashboard no Power BI para facilitar a visualização e a interpretação das informações.

## 📈 Visualizações desenvolvidas

O dashboard conta com três gráficos:

* Soma de anos por entidade: apresenta a soma dos anos agrupados por entidade.
* Soma de anos por código: demonstra a soma dos anos de acordo com cada código.
* Contagem de entidades por código: mostra a quantidade de entidades associadas a cada código.

## 🛠️ Ferramentas utilizadas

* Microsoft Power BI.
* Excel

## 🎯 Objetivo

Transformar os dados abertos em representações visuais, facilitando a análise, a interpretação das informações e a identificação de padrões relacionados à expectativa de vida.

## 📌 Resultado

Foi desenvolvido um dashboard com três visualizações gráficas, proporcionando uma apresentação mais organizada e acessível dos dados analisados.

# 📈 Parte 2: Análise de Dados - Horas de Estudo e Desempenho Acadêmico

## 📝 Sobre a atividade

Após o desenvolvimento dos dashboards no Power BI, foi disponibilizado um link do GitHub contendo uma tabela com dados sobre notas de estudantes e suas respectivas horas de estudo.

A partir dessa base de dados, foi utilizado o Microsoft Excel para organizar as informações e desenvolver uma análise gráfica, buscando compreender a possível relação entre o tempo dedicado aos estudos e o desempenho acadêmico dos estudantes.

## 📊 Análise desenvolvida

Foi construído um gráfico de dispersão, utilizando a regressão linear para analisar a relação entre as duas variáveis:

* Horas de estudo: tempo dedicado pelos estudantes aos estudos.
* Notas dos estudantes: resultados obtidos nas avaliações.

**A análise foi orientada pela seguinte pergunta:**

**“Mais horas de estudo estão associadas a notas maiores?”**

**Resposta:** Sim!
A equação da reta de regressão é: y= 1,6341x + 23,618. Isso significa que, a cada hora adicional de estudo, a nota do exame aumenta, em média, aproximadamente 1,63 pontos.


## 🛠️ Ferramentas e métodos utilizados

* GitHub — acesso à base de dados.
* Microsoft Excel — organização dos dados e elaboração do gráfico.
* Gráfico de dispersão — visualização da relação entre as variáveis.
* Regressão linear — análise da tendência de associação entre as horas de estudo e as notas.

## 📌 Resultado

A atividade possibilitou a aplicação prática de técnicas de análise de dados, permitindo observar graficamente a relação entre as horas de estudo e as notas dos estudantes, além de utilizar a regressão linear como recurso para interpretar essa associação.

# 💻 Parte 3: Modelagem de Regressão Linear - Google Colab

## 📝 Sobre a atividade

Dando continuidade à análise dos dados sobre horas de estudo e notas dos estudantes, foi proposta uma terceira etapa da atividade, utilizando o Google Colab para desenvolver um modelo de regressão linear a partir da mesma base de dados utilizada anteriormente.

## 📊 Desenvolvimento da análise

Foi utilizado o Google Colab para construir um modelo de regressão linear, considerando as mesmas variáveis da etapa anterior:

* Horas de estudo: variável utilizada para analisar o tempo dedicado pelos estudantes aos estudos.
* Notas dos estudantes: variável utilizada para representar o desempenho acadêmico.

Após a construção do modelo, foi realizada uma comparação com o modelo de regressão linear desenvolvido anteriormente no Microsoft Excel.

## 🔍 Comparação dos modelos

A comparação teve como objetivo verificar se os dois modelos apresentam os mesmos resultados, observando possíveis diferenças nos coeficientes da regressão, na inclinação da reta e nas previsões realizadas.
