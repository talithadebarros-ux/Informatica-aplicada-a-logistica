# 📊 Power BI com Figuras

## 📌 Descrição do Projeto

Neste projeto, trabalhamos com um conjunto de dados abertos sobre estabelecimentos de saúde, contendo informações sobre seus respectivos CNAEs (Classificação Nacional de Atividades Econômicas), serviços especializados, tipos de estabelecimentos, entre outros dados relevantes.

Após a análise inicial, os dados foram importados para o Power BI, onde desenvolvemos dashboards interativos para facilitar a visualização, a interpretação e a análise das informações.

## 🎯 Objetivo

Explorar dados abertos relacionados aos estabelecimentos de saúde e transformá-los em visualizações interativas, tornando as informações mais claras, acessíveis e fáceis de compreender.

## 🛠️ Ferramentas Utilizadas

* Power BI: criação de dashboards interativos e visualização de dados.
* Dados abertos: fonte das informações utilizadas no projeto.

## 📈 Resultados

O projeto possibilitou a organização e a visualização dos dados sobre os estabelecimentos de saúde por meio de dashboards interativos, facilitando a identificação e a análise das informações disponíveis.
