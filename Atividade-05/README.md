# Projeto — Empresas Multimodais

## 📌 Descrição

Neste projeto, trabalhamos com dados extraídos da ANTT (Agência Nacional de Transportes Terrestres) relacionados a empresas de transporte multimodal.

Para facilitar a visualização e interpretação das informações, utilizamos o Power BI na criação de dashboards interativos.

## 🎯 Objetivo

O objetivo do projeto foi transformar dados em informações visuais e interativas, facilitando a análise e a compreensão dos dados relacionados às empresas multimodais.

## 📊 Desenvolvimento

Os dados disponibilizados pela ANTT foram trabalhados e apresentados por meio de dashboards no Power BI, utilizando recursos de visualização de dados para organizar as informações de maneira clara e dinâmica.

A utilização de gráficos, indicadores e outros elementos visuais permitiu apresentar os dados de forma mais interativa e facilitar a análise das informações.

## 🛠️ Ferramenta utilizada

* Power BI — utilizado para tratamento, análise e criação dos dashboards e visualizações interativas.
