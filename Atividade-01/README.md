# Atividade 01 — Quem é Quem?

## 📌 Descrição

Nesta atividade, desenvolvemos uma apresentação em slides com o tema “Quem é Quem”, com o objetivo de apresentar os integrantes do grupo de uma forma dinâmica e interativa.

Cada integrante realizou uma apresentação pessoal, abordando três assuntos em comum definidos pelo grupo.

## 🎯 Objetivo

O objetivo da atividade foi promover a interação entre os integrantes do grupo, permitindo que todos conhecessem melhor uns aos outros de uma maneira descontraída.

Para tornar a apresentação mais interativa, foram elaboradas perguntas e curiosidades sobre cada integrante, fazendo com que os participantes tentassem descobrir quem era quem a partir das informações apresentadas.
